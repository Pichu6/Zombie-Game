# Tier 0 playtests (stage 10: kill or keep)

Written up as runs happen. The plan ([plan.md](plan.md) stage 10) asks for at least 5 full runs, some by other players, on seeds both with and without the stranger's hidden bite (the debug truth shows it, F1), and answers to the seven fun questions before any renderer work. If an answer is no, the design changes first.

The telemetry file (`telemetry_seed<N>.jsonl` next to the exe) answers 1, 2 and 4 in numbers; the end screen's four questions answer 3, 5 and 7; 6 comes from the job board choices.
