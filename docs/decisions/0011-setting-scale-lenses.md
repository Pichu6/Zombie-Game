# 0011 · Setting, scale and the three lenses

- **Date:** 2026-10-05
- **Status:** Decided by the user (scale numbers are a Proposal)

## Decisions

- **Era:** present day, modern world.
- **Scale:** the world must feel big enough for big-picture play, but a realistic 1:1 city is too much. Proposal for the numbers: a compressed small town as the final target (real building sizes, fewer buildings), grown tier by tier from one block.
- **Three lenses on one zoom:** manager (big picture) → isometric (tactical) → 2nd/3rd person (immersion), moving continuously on the same world and the same survivor. Extends [0008](0008-controls-cameras.md).
