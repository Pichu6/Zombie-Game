# 0021 · Recommended options accepted: scale, walking speed, pressure bar, cure default

- **Date:** 2026-10-06
- **Status:** Decided by the user ("recommended options for all").

## Decisions

1. **Local zone:** a cropped piece of the real town, thinning only filler buildings if needed, never moving key buildings.
2. **Walking speed:** bodies walk at real speed while the calendar runs 24×; the zone is sized for it.
3. **Pressure bar:** each region on the globe shows one collapse-pressure bar computed from the simulation's forecast, fogged while playing an individual.
4. **Cure default** (left as a Proposal in [0018](0018-sandbox-answers.md)): treatment works before turning, a vaccine is a lab project, nothing cures a turned zombie; all of it adjustable in Sandbox.
5. **Hands-on activities** pay off by reaching the upper part of the character's own range, never above it ([activities](../design/activities.md)).

Scale details: [world simulation](../design/world-simulation.md) section 8.
