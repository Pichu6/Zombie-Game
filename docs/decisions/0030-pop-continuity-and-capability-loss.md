# 0030 · One pop at every layer, pop templates, hidden mystery, capability loss both ways

- **Date:** 2026-10-06
- **Status:** Decided by the user (answers to [0029](0029-leader-records-foxhole-tech-readout.md)). Models are Proposals in [sandbox parameters](../design/sandbox-parameters.md) and [pop continuity](../design/pop-continuity.md).

## Decisions

1. **Pop templates:** a preset pop is a template made once per world, plus an optional import as a copy.
2. **Mystery outbreak:** the cause is hidden by default, with a sandbox "reveal" button that tags the save.
3. **A pop is the same at every layer** of the simulation: the same person, whether seen as a number, a marker or a body.
4. **War is secondary for now.** It waits for the Foxhole research ([research](../research/foxhole.md)).
5. **Capabilities can be lost, not forgotten.** If a nation can't sustain something, it reflects down; if a shop closes, its workers become displaced pops; if a hospital lacks workers it can shut down, and that reflects up. Examples: some ammunition no longer found in an area after a tech loss; a factory disabled so that enabling it again is no longer possible (see the open point below).

## Open point (needs the user)

The last example has two readings: re-enabling a lost capability is **impossible**, or it is possible but **pops (AI) won't do it, only a human player with that as a mission**. Both fit the rules (the AI is cautious by design, [vision](../vision.md)). Recommendation: possible but hard and slow, and the AI never takes it on its own; the player can take it as a mission.
