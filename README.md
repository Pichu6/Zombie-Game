# Juego Zombie

A zombie survival game with deep simulation, on our own C++ and Vulkan engine.

This repository holds the engine and the game: `engine/`, `apps/`, `data/`, `tools/`, `third_party/`.
Research notes, design documents and decisions are kept locally, not in this repository.

Build: `cmake --preset release` then `cmake --build --preset release`. `zs.exe --help` lists the modes.
